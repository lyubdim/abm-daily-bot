## Оставшиеся приёмочные действия

1. Добавить `OPENAI_API_KEY` в локальный `.env.prod.local` и пройти живой сценарий
   совета с уточняющим вопросом. Без ключа бот безопасно использует конкретный
   локальный fallback, но это не считается проверкой настоящего AI.
2. Вручную пройти `/weekly`, PM-команды и искусственно состаренное затруднение по
   `docs/e2e_test_plan.md`, сохранив обезличенные скриншоты.
3. Перед передачей руководителю заменить опубликованный ранее Telegram token и
   перезапустить локальный контейнер.
4. Пока бот работает локально, компьютер разработчика и Docker Desktop должны быть
   включены. Постоянная независимая работа относится к следующему этапу deployment.
