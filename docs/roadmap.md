- Создать GitHub-репозиторий.

- Получить тестовые доступы к Odoo.

## Этап 1. Odoo discovery

- Проверить версию Odoo через `/web/version`.
- Проверить доступность внешнего API.
- Найти технические имена моделей и полей.
- Получить список задач по пользователю.
- Проверить обновление статуса тестовой задачи.
- Проверить запись комментария в chatter.

Результат для практики: документ `Odoo API discovery`, скриншоты/логи тестовых запросов без секретов.
