# Practice Report Outline

## Тема

Разработка Telegram-бота для автоматизации daily-status процесса и синхронизации задач с Odoo в проекте ABM Club.

## Актуальность

В проектной команде статусы задач часто собираются вручную: участникам нужно заходить в Odoo, обновлять статусы, оставлять комментарии и отдельно сообщать PM о затруднениях. Это создаёт лишнюю рутину и снижает прозрачность работы. Telegram-бот переносит короткий ежедневный процесс в привычный канал общения и автоматически сохраняет результаты в Odoo.

## Цель работы

Создать MVP Telegram-бота, который:

- получает список открытых задач участника из Odoo;
- собирает ежедневный прогресс;
- обновляет статус задачи;
- фиксирует затруднения и ссылки на результат;
- формирует AI-рекомендации по затруднениям;
- отправляет PM дайджесты и эскалации.

## Задачи практики

1. Изучить Odoo API, Telegram Bot API и подходы к хранению секретов.
2. Спроектировать архитектуру интеграции.
3. Реализовать базовый Telegram-сценарий ежедневного опроса.
4. Реализовать запись результата в Odoo.
5. Добавить надёжную очередь повторной доставки.
6. Реализовать AI-советы по затруднениям.
7. Подготовить документацию и инструкцию запуска.

## Объект и предмет

Объект: процесс управления задачами команды в Odoo.

Предмет: автоматизация сбора статусов через Telegram-бота и синхронизация данных с Odoo.
