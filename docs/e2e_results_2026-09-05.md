## Defects found during acceptance

1. Empty optional `PUBLIC_BASE_URL` stopped application startup. Fixed in `6c66f1d`.
2. An existing Odoo user mapping caused a uniqueness failure on a new Telegram binding.
   Fixed in `24f18fc` with a regression test.
3. Windows startup diagnostics reported a false stop while polling was active.
   Fixed in `18c56b0`.
4. Telegram-based outbox keys created a duplicate after an account rebind. The key now
   uses the stable Odoo user ID and adopts the latest legacy row.
5. Task links opened the customer portal preview instead of the internal task card.
   Links now target `/odoo/project.task/{id}` for daily and assignment notifications.
6. Initial `message_post` escaped formatting in the internal chatter. New daily and
   blocker messages now explicitly pass `body_is_html=True`.
